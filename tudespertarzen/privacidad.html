Política de privacidad de Tu Despertar Zen

Última actualización: 11 de noviembre de 2026

1. Qué es esta aplicación

Tu Despertar Zen es una aplicación de uso interno que gestiona el canal de YouTube @TuDespertarZen y sus copias de seguridad. No está dirigida al público general.

2. Datos a los que accede

YouTube Data API: vídeos, descripciones, listas de reproducción y comentarios del canal propio, solo para publicar contenido y gestionar la comunidad del canal.

YouTube Analytics API (solo lectura): métricas del canal propio, para medir el rendimiento de las publicaciones.

Google Drive: archivos de la carpeta de copias de seguridad del canal en la cuenta de respaldo del titular. No se usan otros archivos de Drive.

3. Uso de los datos

Los datos se usan exclusivamente para las funciones descritas. No se venden, no se ceden a terceros y no se usan con fines publicitarios. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

4. Conservación y revocación

Las credenciales de acceso se guardan solo mientras son necesarias para operar el canal. El titular puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.
