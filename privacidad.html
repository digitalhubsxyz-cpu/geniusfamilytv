Política de privacidad de GeniusFamilyTV

Última actualización: 10 de noviembre de 2026

1. Qué es esta aplicación

GeniusFamilyTV es una aplicación de uso interno que gestiona el canal de YouTube @GeniusFamilyTV y sus copias de seguridad. No está dirigida al público general.

2. Datos a los que accede

  • YouTube Data API: vídeos, descripciones y comentarios del canal propio, solo para publicar contenido y gestionar la comunidad del canal.
  • Google Drive (permiso drive.file): únicamente los archivos que la propia aplicación crea, para guardar copias de seguridad del canal. No accede a ningún otro archivo de Drive.

3. Uso de los datos

Los datos se usan exclusivamente para las funciones descritas. No se venden, no se ceden a terceros y no se usan con fines publicitarios. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

4. Conservación y seguridad

Los tokens de acceso se guardan de forma privada y solo durante el tiempo necesario para prestar el servicio.

5. Revocar el acceso

Puedes retirar el permiso en cualquier momento desde myaccount.google.com/permissions.
